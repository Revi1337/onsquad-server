[[crew-create]]
=== 크루 생성

`+POST /api/crews+`

크루를 만듭니다. 만든 회원이 크루장(`OWNER`)이 됩니다.

요청은 `multipart/form-data` 이며 `request` 파트에 JSON, `file` 파트에 대표 이미지(선택)를 담습니다. 이름, 소개, 상세 설명, 해시태그를 설정합니다.

[horizontal]
인증:: 필수

[[crew-main]]
=== 크루 메인 조회

`+GET /api/crews/{crewId}/main+`

크루 메인 화면에 필요한 정보를 한 번에 내려줍니다. 크루 정보, 공지, 랭커, 스쿼드 목록이 포함됩니다.

[horizontal]
인증:: 필수
권한:: 크루 멤버

`page`, `size` 는 함께 내려오는 스쿼드 목록의 페이징입니다.

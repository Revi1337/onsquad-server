[[crew-request]]
== 크루 가입 신청

크루 가입 신청과 승인/거절 API 입니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|POST
|`+/api/crews/{crewId}/requests+`
|<<crew-request-request,크루 가입 신청>>
|필수

|GET
|`+/api/crews/{crewId}/requests+`
|<<crew-request-list,크루 가입 신청 목록 조회>>
|필수

|PATCH
|`+/api/crews/{crewId}/requests/{requestId}+`
|<<crew-request-accept,크루 가입 승인>>
|필수

|DELETE
|`+/api/crews/{crewId}/requests/{requestId}+`
|<<crew-request-reject,크루 가입 거절>>
|필수

|DELETE
|`+/api/crews/{crewId}/requests/me+`
|<<crew-request-cancel,내 크루 가입 신청 취소>>
|필수

|GET
|`+/api/members/me/crew-requests+`
|<<crew-request-my-requests,내 크루 가입 신청 내역 조회>>
|필수

|===

[[crew-request-request]]
=== 크루 가입 신청

`+POST /api/crews/{crewId}/requests+`

크루에 가입을 신청합니다. 같은 신청을 연속으로 보내면 요청 제한으로 `429` 가 내려옵니다.

인증:: 필수

[[announce]]
== 크루 공지

크루 공지사항 작성, 조회, 수정, 삭제, 상단 고정 API 입니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|POST
|`+/api/crews/{crewId}/announces+`
|<<announce-create,공지 작성>>
|필수

|GET
|`+/api/crews/{crewId}/announces+`
|<<announce-list,공지 목록 조회>>
|필수

|GET
|`+/api/crews/{crewId}/announces/{announceId}+`
|<<announce-find,공지 단건 조회>>
|필수

|PUT
|`+/api/crews/{crewId}/announces/{announceId}+`
|<<announce-update,공지 수정>>
|필수

|PATCH
|`+/api/crews/{crewId}/announces/{announceId}/pin+`
|<<announce-pin,공지 상단 고정 변경>>
|필수

|DELETE
|`+/api/crews/{crewId}/announces/{announceId}+`
|<<announce-delete,공지 삭제>>
|필수

|===

[[announce-list]]

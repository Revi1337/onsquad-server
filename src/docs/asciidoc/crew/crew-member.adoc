[[crew-member]]
== 크루 멤버

크루 참여자 관리와 리더보드 API 입니다. 크루 안에서의 역할은 `OWNER`(크루장), `MANAGER`(매니저), `GENERAL`(일반) 입니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|GET
|`+/api/crews/{crewId}/members+`
|<<crew-member-list,크루 멤버 목록 조회>>
|필수

|PATCH
|`+/api/crews/{crewId}/members/{targetMemberId}/owner+`
|<<crew-member-delegate-owner,크루장 위임>>
|필수

|DELETE
|`+/api/crews/{crewId}/members/me+`
|<<crew-member-leave,크루 탈퇴>>
|필수

|DELETE
|`+/api/crews/{crewId}/members/{targetMemberId}+`
|<<crew-member-kick,크루원 추방>>
|필수

|GET
|`+/api/crews/{crewId}/leaderboard+`
|<<crew-member-leaderboard,크루 리더보드 조회>>
|필수

|GET
|`+/api/members/me/crew-participants+`
|<<crew-member-my-crews,내가 참여 중인 크루 조회>>
|필수

|===

[[crew-member-list]]
=== 크루 멤버 목록 조회

`+GET /api/crews/{crewId}/members+`

크루 참여자 목록을 조회합니다. 각 멤버에 대해 나 자신인지(`isMe`), 추방할 수 있는지(`canKick`), 크루장을 위임할 수 있는지(`canDelegateOwner`)가 함께 내려옵니다.

[horizontal]
인증:: 필수
권한:: 크루 매니저 이상

[[crew-member-leave]]
=== 크루 탈퇴

`+DELETE /api/crews/{crewId}/members/me+`

크루에서 탈퇴합니다. 크루장은 권한을 위임한 뒤에만 탈퇴할 수 있고, 마지막 한 명이 탈퇴하면 크루가 함께 삭제됩니다.

인증:: 필수
권한:: 크루 멤버

[[crew-member-leaderboard]]
=== 크루 리더보드 조회

`+GET /api/crews/{crewId}/leaderboard+`

크루의 주간 활동 점수 랭킹을 조회합니다. 크루 가입, 스쿼드 생성/참여, 댓글 활동에 점수가 부여되며 매주 월요일 0시에 집계됩니다.

[horizontal]
인증:: 필수
권한:: 크루 멤버

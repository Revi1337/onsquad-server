[[squad-comment]]
== 스쿼드 댓글

스쿼드 댓글과 대댓글 API 입니다. 대댓글은 1단계만 지원합니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|POST
|`+/api/squads/{squadId}/comments+`
|<<squad-comment-create,댓글 작성>>
|필수

|GET
|`+/api/squads/{squadId}/comments+`
|<<squad-comment-list,댓글 목록 조회>>
|필수

|POST
|`+/api/squads/{squadId}/comments/{parentId}/replies+`
|<<squad-comment-reply-create,대댓글 작성>>
|필수

|GET
|`+/api/squads/{squadId}/comments/{parentId}/replies+`
|<<squad-comment-reply-list,대댓글 목록 조회>>
|필수

|PATCH
|`+/api/squads/{squadId}/comments/{commentId}+`
|<<squad-comment-update,댓글 수정>>
|필수

|DELETE
|`+/api/squads/{squadId}/comments/{commentId}+`
|<<squad-comment-delete,댓글 삭제>>
|필수

|===

[[squad-comment-create]]
=== 댓글 작성

`+POST /api/squads/{squadId}/comments+`

스쿼드에 댓글을 작성합니다. 내용은 250자 이하여야 합니다.

[horizontal]
인증:: 필수
권한:: 크루 멤버

[[squad-comment-list]]
=== 댓글 목록 조회

`+GET /api/squads/{squadId}/comments+`

스쿼드의 댓글 목록을 조회합니다. 삭제된 댓글은 `삭제된 댓글입니다.` 로 마스킹되어 내려옵니다.

대댓글은 <<squad-comment-reply-list,대댓글 목록 조회>> API 로 따로 조회합니다.

인증:: 필수

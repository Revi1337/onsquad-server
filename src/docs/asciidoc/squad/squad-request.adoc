[[squad-request]]
== 스쿼드 참가 신청

스쿼드 참가 신청과 승인/거절 API 입니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|POST
|`+/api/squads/{squadId}/requests+`
|<<squad-request-request,스쿼드 참가 신청>>
|필수

|GET
|`+/api/squads/{squadId}/requests+`
|<<squad-request-list,스쿼드 참가 신청 목록 조회>>
|필수

|PATCH
|`+/api/squads/{squadId}/requests/{requestId}+`
|<<squad-request-accept,스쿼드 참가 승인>>
|필수

|DELETE
|`+/api/squads/{squadId}/requests/{requestId}+`
|<<squad-request-reject,스쿼드 참가 거절>>
|필수

|DELETE
|`+/api/squads/{squadId}/requests/me+`
|<<squad-request-cancel,내 스쿼드 참가 신청 취소>>
|필수

|GET
|`+/api/members/me/squad-requests+`
|<<squad-request-my-requests,내 스쿼드 참가 신청 내역 조회>>
|필수

|===

[[squad-request-request]]
=== 스쿼드 참가 신청

`+POST /api/squads/{squadId}/requests+`

스쿼드에 참가를 신청합니다. 이미 참여 중인 스쿼드에는 신청할 수 없습니다.

인증:: 필수
권한:: 크루 멤버

=== 스쿼드 참가 승인

[[squad]]
== 스쿼드

크루 안에서 열리는 소규모 활동 모임인 스쿼드의 생성, 조회, 삭제 API 입니다. 스쿼드는 크루 안에서만 만들 수 있습니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|POST
|`+/api/crews/{crewId}/squads+`
|<<squad-create,스쿼드 생성>>
|필수

|GET
|`+/api/crews/{crewId}/squads+`
|<<squad-list,스쿼드 목록 조회>>
|필수

|GET
|`+/api/crews/{crewId}/squads/manage+`
|<<squad-manage-list,스쿼드 관리 목록 조회>>
|필수

|GET
|`+/api/squads/{squadId}+`
|<<squad-find,스쿼드 단건 조회>>
|필수

|DELETE
|`+/api/squads/{squadId}+`
|<<squad-delete,스쿼드 삭제>>
|필수

|===

[[squad-create]]
=== 스쿼드 생성

`+POST /api/crews/{crewId}/squads+`

크루 안에 스쿼드를 만듭니다. 만든 회원이 리더(`LEADER`)가 됩니다.

카테고리는 최대 5개, 모집 인원은 2~1,000명까지 설정할 수 있습니다.

[horizontal]
인증:: 필수
권한:: 크루 멤버

=== 스쿼드 관리 목록 조회

[[squad-member]]
== 스쿼드 멤버

스쿼드 참여자 관리 API 입니다. 스쿼드 안에서의 역할은 `LEADER`(리더), `GENERAL`(일반) 입니다.

.엔드포인트 목록
[cols="1,4,4,1",options="header"]
|===
|Method|Path|설명|인증

|GET
|`+/api/squads/{squadId}/members+`
|<<squad-member-list,스쿼드 멤버 목록 조회>>
|필수

|PATCH
|`+/api/squads/{squadId}/members/{targetMemberId}/leader+`
|<<squad-member-delegate-leader,스쿼드 리더 위임>>
|필수

|DELETE
|`+/api/squads/{squadId}/members/me+`
|<<squad-member-leave,스쿼드 탈퇴>>
|필수

|DELETE
|`+/api/squads/{squadId}/members/{targetMemberId}+`
|<<squad-member-kick,스쿼드원 추방>>
|필수

|GET
|`+/api/members/me/squad-participants+`
|<<squad-member-my-squads,내가 참여 중인 스쿼드 조회>>
|필수

|===

[[squad-member-list]]
=== 스쿼드 멤버 목록 조회

`+GET /api/squads/{squadId}/members+`

스쿼드 참여자 목록을 조회합니다. 각 멤버에 대한 `isMe`, `canKick`, `canDelegateLeader` 상태가 함께 내려옵니다.

[horizontal]
인증:: 필수
권한:: 스쿼드 참여자 또는 크루장

[[squad-member-leave]]
=== 스쿼드 탈퇴

`+DELETE /api/squads/{squadId}/members/me+`

스쿼드에서 탈퇴합니다. 리더는 권한을 위임한 뒤에만 탈퇴할 수 있고, 마지막 한 명이 탈퇴하면 스쿼드가 함께 삭제됩니다.

인증:: 필수
권한:: 스쿼드 참여자

[[notification-sse]]
=== 실시간 알림 구독 (SSE)

`+GET /api/notifications/sse+`

`text/event-stream` 으로 실시간 알림을 구독합니다. 크루/스쿼드 가입 신청, 승인, 거절, 댓글, 대댓글이 대상자에게 전달됩니다.

알림은 DB 에 먼저 저장한 뒤 전송하므로, 연결이 끊긴 동안의 알림은 재연결할 때 `Last-Event-ID` 헤더로 이어서 받을 수 있습니다. 연결 유지를 위해 45초마다 heartbeat 가 전송됩니다.

[horizontal]
인증:: 필수

SSE 는 `Authorization` 헤더 대신 `accessToken` 쿼리 파라미터로 인증합니다. 내가 나에게 보내는 알림은 만들어지지 않습니다.

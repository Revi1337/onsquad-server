[[overview]]
== 개요

OnSquad 는 취미/운동 모임 플랫폼입니다. 사용자는 **크루(Crew)** 라는 커뮤니티를 만들고, 그 안에서 **스쿼드(Squad)** 라는 소규모 활동 모임을 열어 참여자를 모집합니다.
이 문서는 OnSquad 서버가 제공하는 REST API 를 도메인별로 정리한 것입니다.

=== 기본 규칙

* 모든 API 는 `/api` 아래에 있습니다.
* 요청과 응답 본문은 `application/json` 입니다. 파일을 올리는 API 만 `multipart/form-data` 를 씁니다.
* 아래 응답 형식은 소셜 로그인(`/api/login/oauth2/**`)과 SSE(`/api/notifications/sse`)를 제외한 모든 API 에 적용됩니다.

=== 인증

인증이 필요한 API 는 `Authorization` 헤더에 로그인으로 받은 Access Token 을 담아 호출합니다.

[source,http]
----
Authorization: Bearer {accessToken}
----

* 각 API 의 *인증* 항목이 `필수` 이면 토큰이 있어야 하고, `선택` 이면 토큰이 없어도 호출할 수 있지만 보내면 로그인 사용자 기준의 정보가 더해집니다.
* Access Token 이 만료되면 `401`(`T003`)이 내려옵니다. <<auth-reissue,토큰 재발급>> 으로 새 토큰을 받아 다시 호출하세요.
* SSE 구독은 헤더 대신 `accessToken` 쿼리 파라미터를 사용합니다. <<notification-sse,실시간 알림 구독>> 을 참고하세요.

=== 응답 형식

성공 응답은 항상 같은 형태입니다. HTTP 상태 코드는 본문의 `status` 와 같습니다.

[source,json]
----
{
  "status": 200,
  "success": true,
  "data": {}
}
----

* 조회/수정/삭제 같은 성공은 `200`, 생성은 `201` 입니다.
* 응답 데이터가 없는 성공도 상태 코드는 `200`(또는 `201`)이고, 이때 `data` 는 빈 문자열(`""`)입니다.

실패 응답은 `success` 가 `false` 이고 `data` 대신 `error` 가 내려옵니다. 유효성 검증에 실패하면 `parameters` 에 문제가 된 필드 이름이 담깁니다.

[source,json]
----
{
  "status": 400,
  "success": false,
  "error": {
    "code": "C001",
    "message": "유효성 검증 실패",
    "parameters": [
      "nickname"
    ]
  }
}
----

에러 코드의 전체 목록은 <<error-codes,에러 코드>> 장에서 볼 수 있습니다.

=== 상태 코드

[cols="1,6",options="header"]
|===
|코드|의미

|`200`|요청 성공
|`201`|생성 성공
|`302`|소셜 로그인 콜백의 리다이렉트
|`400`|잘못된 요청 (유효성 검증 실패, 규칙 위반 등)
|`401`|인증 실패 (토큰 없음/만료/위조, 로그인 정보 불일치 등)
|`403`|권한 없음 (역할이 부족한 요청)
|`404`|대상을 찾을 수 없음
|`405`|지원하지 않는 HTTP 메서드
|`409`|이미 처리된 요청이거나 동시 요청과 충돌
|`413`|요청 크기 초과
|`415`|지원하지 않는 요청 형식
|`429`|요청 제한 초과 (같은 요청을 짧은 시간에 반복한 경우)
|`500`|서버 오류
|`503`|시스템 점검 중
|===

=== 페이징

목록 API 는 `page`, `size` 쿼리 파라미터로 페이징합니다.

[cols="1,1,4",options="header"]
|===
|파라미터|기본값|설명

|`page`|1|페이지 번호이며 *1부터 시작*합니다.
|`size`|10|한 페이지의 개수이며 최대 100 입니다.
|===

페이징된 응답의 `data` 는 아래 형태입니다.

[cols="1,1,4",options="header"]
|===
|필드|타입|설명

|`page`|Number|현재 페이지
|`size`|Number|요청한 페이지 크기
|`totalPages`|Number|전체 페이지 수
|`totalCount`|Number|전체 건수
|`resultsSize`|Number|이번 페이지에 담긴 건수
|`results`|Array|결과 목록
|===

NOTE: `page=0` 을 보내도 첫 페이지로 처리됩니다. 이 문서의 요청 예시 중 일부가 `page=0` 인 이유입니다.

=== 역할과 권한

크루와 스쿼드에는 역할이 있고, 역할에 따라 호출할 수 있는 API 가 달라집니다. 역할이 부족하면 `403` 이 내려옵니다.

[cols="1,1,5",options="header"]
|===
|범위|역할|할 수 있는 일

|크루
|`OWNER` (크루장)
|크루 수정/삭제, 크루장 위임, 공지 상단 고정, 모든 멤버 관리

|크루
|`MANAGER` (매니저)
|가입 신청 승인/거절, 공지 작성, 참여자 목록 조회, 일반 멤버 관리, 관리 화면 조회

|크루
|`GENERAL` (일반)
|크루 조회, 스쿼드 생성/참여, 댓글 작성

|스쿼드
|`LEADER` (리더)
|참가 신청 승인/거절, 리더 위임, 스쿼드원 추방, 댓글 삭제

|스쿼드
|`GENERAL` (일반)
|스쿼드 참여, 댓글 작성
|===

각 API 의 *권한* 항목에는 호출에 필요한 최소 조건이 적혀 있습니다.
